# Carriage Hill — Places Capital microsite

A single-page marketing microsite for the **Carriage Hill** assemblage (25 lots / ~42 acres,
tax map `157.-2-1`, Carriage Hill Rd, Roxbury, NY 12474). Three tabs:

- **Carriage Hill** — interactive Leaflet map of the lots (street / aerial base), with a
  filterable lot list and a per-lot detail drawer.
- **Why Roxbury** — the Places Capital thesis adapted to Roxbury.
- **Contact** — Places Capital contact details + inquiry mailto.

Static site, no build step. Styled to match placescapital.com (light/editorial; Fraunces +
Inter + Roboto Mono standing in for the licensed "Royale Couture" brand font).

## Run locally
```
cd carriage-hill-microsite
python3 -m http.server 8000
# open http://localhost:8000
```
(Must be served over HTTP — opening `index.html` as a file won't fetch `data/parcels.geojson`.)

## Files
| Path | What |
| --- | --- |
| `index.html` | Markup for all three tabs + nav. |
| `styles.css` | Brand tokens + layout. |
| `app.js` | Tab routing, Leaflet map, filter, lot drawer, contact wiring. Edit `CONTACT` at top. |
| `data/parcels.geojson` | Lot features (geometry + content). Generated by the script below. |
| `scripts/build_parcels.py` | Builds `parcels.geojson`. |

## Lot data

Lot **content** (8 use-types, per-lot notes, perc results) is transcribed from the
*Carriage Hill Lot 1 Pagers* doc into `scripts/build_parcels.py`.

Lot **geometry** is now **real**, from the Regrid Delaware County export:
```
python3 scripts/build_from_regrid.py
```
This reads `../Regrid Parcel Data/parcels/csvwktgz/ny_delaware.csv.gz`, selects the 26 parcels
in tax map `157.-2-*` still owned by the seller ("Giacci, Nancy S Ttee" — the roll hadn't
updated to Places Capital yet post-closing), converts their WKT to GeoJSON, and writes
`data/parcels.geojson` (grouped/colored by street). `scripts/build_parcels.py` (schematic
placeholder) is kept only as a fallback.

**Still to overlay:** the 8 use-type narratives + perc/infra notes from the *Lot 1 Pagers* doc
use the planned subdivision lot numbers (2, 4–7, 17…48), which are NOT the Regrid parcel
suffixes. Add a lot# ↔ parcel (`parcelnumb`) crosswalk to attach that content to the real parcels.

## Deploy (GitHub Pages)
```
git init && git add -A && git commit -m "Carriage Hill microsite"
gh repo create ThesisDriven/carriage-hill-microsite --public --source=. --push
```
Then enable Pages (Settings → Pages → Deploy from `main` / root). Optionally point a custom
subdomain (e.g. `roxbury.placescapital.com`) via a DNS CNAME + a `CNAME` file.
